## Government Scenario

A mission program has multiple trackers for intake, deficiencies, recommendations, corrective actions, milestones, resources, approvals, and reporting. Different offices maintain different versions of status. Leadership receives a consolidated view only after manual reconciliation.

## Government Operating Model

Mission Intake → Internal Review → Governed Record → Recommendation / Action → Milestone → Resource Dependency → Evidence → Approval / Closure → Audit History → Leadership Reporting
