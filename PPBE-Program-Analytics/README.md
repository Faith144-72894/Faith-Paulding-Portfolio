# PPBE Program Analytics

A fictional portfolio project demonstrating analytical support for Planning, Programming, Budgeting, and Execution (PPBE) concepts and program-resource decision support.

> This is a learning and portfolio model. It does not represent actual government budget data or claim direct ownership of an official PPBE process.

## Scenario

A fictional portfolio of mission programs requires a repeatable way to compare requirements, programmed resources, enacted/available funding, execution, milestones, and program health across fiscal years.

## Analytical Components

- Program requirements register
- Fiscal-year funding plan
- Program Objective Memorandum-style planning scenario
- Budget execution tracker
- Unfunded requirement register
- Cost and schedule variance
- 30/60/90-day forecast
- Program health scoring
- Decision log

## Program Health Model

```text
GREEN  = execution and schedule within approved thresholds
AMBER  = emerging funding, schedule, milestone, or risk concern
RED    = critical threshold exceeded or leadership decision required
```

## Example Dataset Fields

| Field | Purpose |
|---|---|
| Program_ID | Unique fictional program key |
| Fiscal_Year | Planning/execution year |
| Requirement | Validated resource need |
| Planned_Funding | Planning baseline |
| Available_Funding | Current fictional funding level |
| Obligations | Fictional obligations to date |
| Forecast | Projected year-end requirement |
| Variance | Difference from plan |
| Health | Green/Amber/Red status |
| Decision_Required | Leadership action flag |
